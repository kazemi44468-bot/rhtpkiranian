مرکز فرماندهی عملیات شرکت

نمایی متمرکز برای مشاهده پرونده‌ها، ارجاع، اولویت‌بندی، کنترل وضعیت، شبکه تأمین و فرصت‌های پروژه. داده‌های زیر در این نسخه نمونه هستند و برای نمایش ساختار مدیریتی طراحی شده‌اند.

این نسخه یک نمونه مدیریتی سمت کاربر است. داده‌های واقعی پس از اتصال احراز هویت، پایگاه داده و API جایگزین داده محلی می‌شوند؛ بنابراین این صفحه به‌عنوان پنل عملیاتی نهاییِ سازمانی تلقی نمی‌شود.
